# Virtual TourBox v0.2.5 预览版

手柄控制 Windows 快捷键，或通过 Windows BLE HID 桥接操作 iPad Procreate。

普通用户下载 VirtualTourBox-v0.2.5-preview-win-x64.zip，完整解压后运行 VirtualTourBox.exe。自包含包无需另装.NET，请先退出旧版和其他BleHid进程。

本版新增独立长按：X短按画笔/长按临时涂抹，Y短按橡皮擦/长按临时橡皮擦；A/B配对连续重做/撤销。已有配置不覆盖，采用新默认请按README恢复默认映射。

新增功能已通过自动检查，但尚未完成本版iPad实机验收，按预览版使用。
历史测试主要来自L1807，不能保证所有官方手柄。
画布平移/旋转/缩放、一键液化/翻转未实现；选中与实际按下同色仍待优化。
项目主体禁止未经许可发布修改版，第三方组件原有许可保持不变。
